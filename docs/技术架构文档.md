### 模块职责说明

| 模块 | 依赖关系 | 职责 |
|------|----------|------|
| **common** | 被所有模块依赖 | 基础设施：工具类、异常处理、统一返回 |
| **payment** | 被 voucher/order/admin 依赖 | 支付核心，枢纽模块 |
| **voucher** | 被 order/admin 依赖 | 优惠券/代金券/秒杀 |
| **order** | 依赖 voucher/payment | 订单服务 |
| **forum** | 依赖 user/merchant/message/search | 论坛社区 |
| **user** | 无强依赖 | 用户中心 |
| **admin** | 依赖多个业务模块 | 后台管理聚合层 |
| **ai** | 独立模块 | AI 对话服务 |

## 3. 数据库连接逻辑

### 3.1 连接配置

**数据源配置（application-dev.yml）**
```yaml
spring:
  datasource:
    url: ${SPRING_DATASOURCE_URL}
    username: ${SPRING_DATASOURCE_USERNAME}
    password: ${SPRING_DATASOURCE_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      maximum-pool-size: 40
      minimum-idle: 10
```

### 3.2 MyBatis 配置

```java
@Configuration
@MapperScan({
    "com.campus.campus_life_backend.modules.admin.mapper",
    "com.campus.campus_life_backend.modules.forum.mapper",
    "com.campus.campus_life_backend.modules.merchant.mapper",
    "com.campus.campus_life_backend.modules.message.mapper",
    "com.campus.campus_life_backend.modules.payment.mapper",
    "com.campus.campus_life_backend.modules.user.mapper",
    "com.campus.campus_life_backend.modules.voucher.mapper"
})
```

# 静态资源和用户资源存储最佳实践

## 一、资源分类

### 1. 静态资源（Static Resources）
- **定义**：项目代码中固定的资源文件，不会动态变化
- **示例**：
  - 前端构建后的 JS、CSS 文件
  - 项目 Logo、默认头像、占位图
  - 前端打包后的静态资源
- **特点**：版本控制、可缓存、CDN 加速

### 2. 用户资源（User-Generated Content）
- **定义**：用户上传的动态内容
- **示例**：
  - 用户头像
  - 帖子图片
  - 学生证照片
  - 商家营业执照
- **特点**：动态生成、需要持久化存储、访问频繁

## 二、存储方案对比

### 方案一：本地存储（当前方案）

**配置**（`application-dev.yml`）：
```yaml
file:
  upload:
    path: uploads  # 项目根目录下的 uploads 文件夹
    url-prefix: /uploads
```

**优点**：
- ✅ 实现简单，无需额外配置
- ✅ 开发环境快速上手
- ✅ 成本低（无需云服务费用）

**缺点**：
- ❌ 服务器磁盘空间有限
- ❌ 单点故障风险
- ❌ 扩展性差（多服务器部署困难）
- ❌ 备份困难
- ❌ 访问速度受服务器带宽限制
- ❌ 服务器重启可能丢失数据（如果未持久化）

**适用场景**：
- 开发/测试环境
- 小型项目（用户量 < 1000）
- 内网应用

### 方案二：云对象存储（推荐生产环境）

#### 2.1 阿里云 OSS
```yaml
aliyun:
  oss:
    endpoint: oss-cn-beijing.aliyuncs.com
    access-key-id: your-access-key-id
    access-key-secret: your-access-key-secret
    bucket-name: campus-life-uploads
    url-prefix: https://campus-life-uploads.oss-cn-beijing.aliyuncs.com
```

#### 2.2 腾讯云 COS
```yaml
tencent:
  cos:
    region: ap-beijing
    secret-id: your-secret-id
    secret-key: your-secret-key
    bucket-name: campus-life-uploads
    url-prefix: https://campus-life-uploads.cos.ap-beijing.myqcloud.com
```

#### 2.3 七牛云
```yaml
qiniu:
  access-key: your-access-key
  secret-key: your-secret-key
  bucket: campus-life-uploads
  domain: https://cdn.yourdomain.com
```

**优点**：
- ✅ 高可用性（99.99%+）
- ✅ 自动备份和冗余
- ✅ 无限扩展
- ✅ CDN 加速，访问速度快
- ✅ 按量付费，成本可控
- ✅ 支持图片处理（缩略图、水印等）
- ✅ 多地域部署

**缺点**：
- ❌ 需要额外配置
- ❌ 产生云服务费用（但通常很便宜）
- ❌ 需要处理跨域问题

**适用场景**：
- ✅ **生产环境（强烈推荐）**
- ✅ 中大型项目
- ✅ 需要高可用性的应用

### 方案三：混合方案

- **静态资源**：CDN（如 Cloudflare、阿里云 CDN）
- **用户资源**：云对象存储（OSS/COS）
- **开发环境**：本地存储

## 三、推荐架构

### 开发环境
```
项目根目录/
├── uploads/          # 本地存储
│   ├── avatars/      # 用户头像
│   ├── posts/        # 帖子图片
│   └── certificates/ # 认证文件
```

### 生产环境
```
用户上传 → 后端API → 云对象存储(OSS/COS)
                ↓
            返回URL → 前端显示
                ↓
            CDN加速访问
```

## 四、目录结构建议

### 用户资源目录结构
```
uploads/
├── avatars/          # 用户头像
│   └── {year}/
│       └── {month}/
│           └── {day}/
│               └── {uuid}.jpg
├── posts/            # 帖子图片
│   └── {year}/
│       └── {month}/
│           └── {day}/
│               └── {uuid}.jpg
├── certificates/     # 认证文件
│   ├── student/      # 学生证
│   └── merchant/     # 营业执照
└── temp/             # 临时文件（定期清理）
```

### 文件命名规范
- 使用 UUID 避免文件名冲突
- 按日期分目录，便于管理和清理
- 保留原始文件名（存储在数据库）

## 五、实施建议

### 阶段一：开发环境（当前）
- ✅ 使用本地存储
- ✅ 配置好目录结构
- ✅ 实现文件上传接口

### 阶段二：测试环境
- 可以继续使用本地存储
- 或者使用云存储的测试 bucket

### 阶段三：生产环境（必须）
- ⚠️ **必须使用云对象存储**
- 配置 CDN 加速
- 设置访问权限（公开/私有）
- 配置图片处理（压缩、缩略图）

## 六、成本估算

### 云存储成本（以阿里云 OSS 为例）
- **存储费用**：0.12元/GB/月
- **流量费用**：0.5元/GB（外网下行）
- **请求费用**：0.01元/万次（PUT/POST）

**示例**：
- 100GB 存储：12元/月
- 100GB 流量：50元/月
- 100万次请求：10元/月
- **总计约：72元/月**

### CDN 成本
- 流量费用：0.24元/GB（国内）
- 100GB 流量：24元/月

## 七、安全建议

1. **文件类型验证**：只允许图片、文档等安全类型
2. **文件大小限制**：防止大文件攻击
3. **访问权限控制**：
   - 公开资源：头像、帖子图片（可公开访问）
   - 私有资源：认证文件（需要签名 URL）
4. **病毒扫描**：上传文件进行安全扫描
5. **防盗链**：配置 Referer 白名单

## 八、迁移方案

如果从本地存储迁移到云存储：

1. **保持接口不变**：只改变存储实现
2. **数据迁移**：将现有文件批量上传到云存储
3. **URL 更新**：更新数据库中的文件 URL
4. **灰度发布**：先迁移新文件，再迁移旧文件

## 九、总结

| 环境 | 静态资源 | 用户资源 | 推荐方案 |
|------|---------|---------|---------|
| 开发 | 本地/打包 | 本地存储 | 本地存储 |
| 测试 | CDN | 云存储测试桶 | 云存储 |
| 生产 | **CDN** | **云对象存储** | **云存储 + CDN** |

**核心原则**：
- 开发环境：简单快速
- 生产环境：**必须使用云存储**，保证高可用性和扩展性

# 支付域开发计划

## 首期目标

- 使用支付宝沙箱打通完整支付闭环
- 保持单体架构，但将支付事实从业务订单中拆出
- 首期只覆盖优惠券订单支付与退款
- 结构预留后续扩展到实物、电商、会员、充值

## 分阶段实施

### 阶段 1：支付域建模

- 新增支付单 `payment_order`
- 新增退款单 `payment_refund_order`
- 新增回调日志 `payment_callback_log`
- 补充对应实体、Mapper、XML、迁移 SQL

### 阶段 2：支付创建与查询

- 创建支付单并绑定业务订单
- 支付金额以后端业务订单为准
- 增加支付单状态查询
- 保留创建支付幂等能力

### 阶段 3：支付宝沙箱闭环

- 接入支付宝沙箱下单
- 异步回调验签、金额校验、状态流转
- 记录原始回调日志
- 完成支付单与业务订单联动

### 阶段 4：退款闭环

- 支持未核销订单退款
- 支持部分退款
- 跟踪累计退款金额
- 业务订单按退款累计金额流转为部分退款或全额退款

### 阶段 5：后台与验证

- 增加支付单、退款单查询入口
- 增加关键链路日志
- 运行测试并补充回归验证说明

## 首期暂不落地

- 微信正式支付
- 真实充值钱包
- 自动分账
- 自动提现

这些能力在结构上预留，但不在支付宝沙箱首期闭环内实现。

# 管理后台响应式设计说明

## 概述

管理后台已实现完整的移动端和PC端适配，确保在不同设备上都能提供良好的用户体验。

## 主要优化内容

### 1. 布局适配 (AdminLayout.vue)

#### PC端特性
- 固定侧边栏（240px宽度）
- 可折叠侧边栏（64px宽度）
- 主内容区域自适应剩余空间

#### 移动端特性
- **抽屉式侧边栏**：默认隐藏，点击菜单按钮打开
- **遮罩层**：侧边栏打开时显示半透明遮罩
- **自动关闭**：点击遮罩或切换路由时自动关闭侧边栏
- **顶部菜单按钮**：在移动端显示汉堡菜单图标

#### 响应式断点
- `≤768px`：移动端布局
- `≤480px`：小屏移动端优化

### 2. 表格适配

#### PC端
- 传统表格布局
- 所有列完整显示
- 操作按钮横向排列

#### 移动端
- **卡片式布局**：每条数据以卡片形式展示
- **关键信息突出**：标题、状态等主要信息在卡片顶部
- **操作按钮优化**：按钮垂直排列，使用较小尺寸
- **统计信息**：点赞数、评论数等以标签形式展示

#### 实现方式
```vue
<!-- PC端表格 -->
<table class="data-table desktop-table">
  <!-- 表格内容 -->
</table>

<!-- 移动端卡片 -->
<div class="mobile-card-list">
  <div class="mobile-card">
    <!-- 卡片内容 -->
  </div>
</div>
```

### 3. 筛选条件适配

#### PC端
- 横向排列
- 使用 flex 布局
- 输入框和按钮在同一行

#### 移动端
- **垂直排列**：所有筛选条件垂直堆叠
- **全宽输入**：输入框和按钮占满宽度
- **更好的触摸体验**：按钮尺寸适合手指点击

### 4. 图表适配

#### 响应式调整
- **图表高度**：移动端适当减小高度（300px → 250px → 200px）
- **字体大小**：标题和标签在小屏设备上缩小
- **图例布局**：自动换行，避免溢出
- **间距优化**：减少内边距，节省空间

#### ECharts 自动适配
- 使用 `chart.resize()` 监听窗口大小变化
- 图表自动重新计算尺寸

### 5. 工作台页面适配

#### 关键指标卡片
- PC端：多列网格布局（auto-fit）
- 移动端：单列布局，卡片间距优化

#### 图表区域
- PC端：3列网格布局
- 移动端：单列布局，图表高度自适应

## 使用方法

### 在其他管理页面应用移动端表格适配

1. **添加移动端卡片列表结构**：
```vue
<!-- 在表格后添加 -->
<div class="mobile-card-list">
  <div v-for="item in list" :key="item.id" class="mobile-card">
    <!-- 卡片内容 -->
  </div>
</div>
```

2. **添加响应式样式**：
```css
@media (max-width: 768px) {
  .desktop-table {
    display: none;
  }
  .mobile-card-list {
    display: block;
  }
}

@media (min-width: 769px) {
  .mobile-card-list {
    display: none;
  }
}
```

### 添加移动端检测

```typescript
import { ref, onMounted, onUnmounted } from 'vue'

const isMobile = ref(false)

const checkMobile = () => {
  isMobile.value = window.innerWidth <= 768
}

onMounted(() => {
  checkMobile()
  window.addEventListener('resize', checkMobile)
})

onUnmounted(() => {
  window.removeEventListener('resize', checkMobile)
})
```

## 最佳实践

### 1. 触摸友好
- 按钮最小点击区域：44x44px
- 输入框高度：至少 40px
- 卡片间距：至少 12px

### 2. 性能优化
- 使用 CSS 媒体查询而非 JavaScript 检测（如可能）
- 避免在移动端加载不必要的资源
- 图表使用懒加载

### 3. 内容优先级
- 移动端优先显示关键信息
- 次要信息可折叠或隐藏
- 操作按钮使用图标+文字或仅图标

### 4. 一致性
- 保持与主应用的设计风格一致
- 使用统一的颜色和间距规范
- 保持交互模式的一致性

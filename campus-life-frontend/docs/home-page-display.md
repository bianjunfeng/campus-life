## 📋 详细组件说明

### 1. 顶部导航栏（HeaderBar）

**位置：** 页面顶部，固定在顶部

**包含内容：**
- **左侧：** 侧边栏按钮（三条横线图标）
  - 点击打开侧边菜单抽屉（SideMenuDrawer）
- **中间：** 导航按钮
  - 首页
  - 福利
  - 消息
  - 我的
- **右侧：** 搜索按钮（放大镜图标）
  - 点击跳转到搜索页面

---

### 2. 标签栏（TabBar）

**位置：** 顶部导航栏下方，可滚动隐藏

**功能：**
- 显示帖子分类标签（从数据库 `post_category` 表获取）
- 默认显示：推荐、学习交流、生活分享、技术讨论等
- 支持左右滑动查看更多标签
- 点击标签可切换显示对应分类的帖子

**标签类型：**
- **推荐（recommend）：** 按时间倒序显示所有帖子
- **发现（discover）：** 按热度（点赞数+评论数）排序
- **热点（hot）：** 按点赞数排序，显示热点排行榜
- **关注（follow）：** 显示关注的用户发布的帖子
- **分类标签：** 根据 `post_category` 表动态加载

---

### 3. 帖子列表（DiscoverPage 主要内容）

**布局：** 两列网格布局（Grid Layout）

**帖子卡片结构：**

```
┌─────────────────────┐
│  👤 用户名   时间    │  ← 作者信息
├─────────────────────┤
│                     │
│      [封面图片]      │  ← 帖子内容
│                     │
├─────────────────────┤
│ ❤️ 12  💬 3         │  ← 互动区域
└─────────────────────┘
```

#### 3.1 作者信息区域

- **用户头像：** 圆形头像，默认占位图
- **用户名：** 帖子作者的用户名
- **发布时间：** 相对时间（如"5分钟前"、"2小时前"）

#### 3.2 帖子内容区域

- **有图片的帖子：**
  - 显示封面图片（1:1 比例，圆角）
  - 图片来自 `post_image` 表的第一张图片
- **没有图片的帖子：**
  - 显示标题占位符（灰色背景，显示标题前6个字符）

#### 3.3 互动区域

- **点赞数：** ❤️ 图标 + 数字（格式化显示，如 1.2k、5.6w）
- **评论数：** 💬 图标 + 数字

**点击行为：**
- 点击帖子卡片 → 跳转到帖子详情页（`/posts/:id`）
- 点击点赞按钮 → 切换点赞状态（前端模拟，需对接后端）

---

### 4. 底部导航栏（NavBar）

**位置：** 页面底部，固定在底部

**包含按钮：**
- **首页：** 当前页面（高亮显示）
- **福利：** 跳转到福利页面（`/welfare`）
- **发布：** 跳转到发布帖子页面（`/posts/new`）
- **消息：** 跳转到消息页面（`/message`）
- **我的：** 跳转到个人中心（`/me`）

---

## 📊 数据来源

### 帖子数据

**API端点：** `GET /api/forum/posts?order=latest&page=1&size=100`

**数据流程：**
1. 前端调用 `fetchPosts()` 函数
2. 请求后端 API
3. 后端查询数据库（`post`、`user`、`post_category`、`post_image` 表）
4. 返回帖子列表数据
5. 前端转换数据格式并渲染

**返回数据格式：**
```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1,
        "title": "帖子标题",
        "content": "帖子内容",
        "coverImage": "https://...",  // 封面图片URL
        "authorName": "用户名",
        "authorAvatar": "头像URL",
        "likeCount": 12,
        "commentCount": 3,
        "createdAt": "2024-12-04T10:30:00",
        "categoryCode": "study"
      }
    ]
  }
}
```

### 分类数据

**API端点：** `GET /api/categories/posts`

**数据来源：** `post_category` 表

## 🎯 页面功能

### 1. 帖子筛选和排序

- **推荐标签：** 按创建时间倒序
- **发现标签：** 按热度排序（点赞数 + 评论数 × 2）
- **热点标签：** 按点赞数降序
- **分类标签：** 按分类筛选，然后按时间排序

### 2. 滚动交互

- **向下滚动：** 标签栏逐渐隐藏
- **向上滚动：** 标签栏重新显示

### 3. 加载状态

- **加载中：** 显示"正在加载帖子..."
- **加载失败：** 显示错误信息
- **无数据：** 显示占位内容

## 🔄 页面交互流程

1. **页面加载：**
   - 显示加载状态
   - 调用 `fetchPosts()` 获取帖子列表
   - 调用 `getPostCategories()` 获取分类列表

2. **标签切换：**
   - 点击标签 → 更新 `activeTab`
   - `filteredPosts` 计算属性自动重新计算
   - 页面重新渲染对应分类的帖子

3. **帖子点击：**
   - 点击帖子卡片 → 调用 `goToPostDetail(post.id)`
   - 路由跳转到 `/posts/:id`

4. **滚动交互：**
   - 监听滚动事件
   - 根据滚动方向显示/隐藏标签栏

## 🐛 常见问题

### 1. 页面显示空白

**可能原因：**
- 后端服务未启动
- API 请求失败
- 数据库中没有帖子数据

**解决方法：**
- 检查后端服务是否运行
- 检查浏览器控制台错误信息
- 执行 `init-test-data.sql` 添加测试数据

### 2. 图片不显示

**可能原因：**
- `post_image` 表中没有数据
- 图片URL无效

**解决方法：**
- 执行测试数据脚本添加图片
- 检查图片URL是否可访问

### 3. 标签栏不显示

**可能原因：**
- 分类数据加载失败
- API 请求错误

**解决方法：**
- 检查 `getPostCategories()` API 是否正常
- 查看浏览器控制台错误信息
